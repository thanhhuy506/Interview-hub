Test Q1. Constructor Order

Answer: C 
class Parent {
    Parent() {
        System.out.println("P");
    }
}

class Child extends Parent {
    Child() {
        System.out.println("C");
    }
}

new Child();

What is printed?

A: C
B: P
C: P C
D: C P
Correct answer: C: P C

When a child object is created, Java calls the parent constructor first, then the child constructor. The parent constructor prints P, then the child constructor prints C.

constructor: hàm khởi tạo parent class: lớp cha child class: lớp con

Test Q2. return in finally

        return 2;

Test Q4. Static Method Hiding

Answer: A 
class A {
    static void run() {
        System.out.println("A");
    }
}

class B extends A {
    static void run() {
        System.out.println("B");
    }
}

public class Main {
    public static void main(String[] args) {
        A a = new B();
        a.run();
    }
}

What is printed?

A: A
B: B
C: A B
D: Runtime error
Correct answer: A: A

Static methods are hidden, not overridden. The method call is resolved using the reference type A, so A.run() is called.

static method hiding: che khuất phương thức static overriding: ghi đè phương thức reference type: kiểu tham chiếu

3. Parallel Counter Race Condition

Answer: B 
class Counter {
    private int value = 0;
    public void inc() { value++; }
    public int get() { return value; }
}

Counter c = new Counter();
IntStream.range(0, 1000).parallel().forEach(i -> c.inc());
System.out.println(c.get());

What is the most likely output?

A: Always 1000
B: Always < 1000
C: Always 0
D: Throws exception
Best answer: B: Always < 1000

The intended point is that value++ is not atomic, so parallel calls can lose updates. Strictly, the result is nondeterministic and could occasionally be 1000, but it is usually less than 1000.

race condition: lỗi tranh chấp luồng atomic: nguyên tử, không bị chia nhỏ lost update: mất cập nhật

13. findMostFrequent(int[] nums)

Coding

Implement a function that finds the number or numbers that occur most frequently in an integer array.

  1. Function: findMostFrequent(int[] nums)
  2. Input: an array of integers nums, which can contain millions of elements.
  3. Output: a list of pairs (number, frequency) representing the most frequently occurring numbers in the array, sorted by frequency in descending order.
public static List<Map.Entry<Integer, Integer>>
findMostFrequent(int[] nums)
Example 1
Input: [1, 3, 2, 1, 4, 2, 1, 3]
Output: [(1, 3)]
Number 1 appears 3 times, the most.
Example 2
Input: [1, 2, 2, 3, 3]
Output: [(2, 2), (3, 2)]
Numbers 2 and 3 both appear 2 times.

Question: return all most-frequent pairs efficiently for a large array.

Correct approach: HashMap frequency count

Count every number, track the maximum frequency, then return entries whose frequency equals that maximum.

Show Java solution 
public static List<Map.Entry<Integer, Integer>> findMostFrequent(int[] nums) {
    Map<Integer, Integer> freq = new HashMap<>();
    int maxFreq = 0;

    for (int num : nums) {
        int count = freq.getOrDefault(num, 0) + 1;
        freq.put(num, count);
        maxFreq = Math.max(maxFreq, count);
    }

    List<Map.Entry<Integer, Integer>> result = new ArrayList<>();
    for (Map.Entry<Integer, Integer> entry : freq.entrySet()) {
        if (entry.getValue() == maxFreq) {
            result.add(new AbstractMap.SimpleEntry<>(entry.getKey(), entry.getValue()));
        }
    }

    result.sort((a, b) -> {
        int byFrequency = Integer.compare(b.getValue(), a.getValue());
        if (byFrequency != 0) return byFrequency;
        return Integer.compare(a.getKey(), b.getKey());
    });

    return result;
}
frequency: tần suất HashMap: bảng băm key-value time complexity: độ phức tạp thời gian

14. Concatenated Substring

Coding

You are given a string s and an array of strings words. All strings in words have the same length.

A concatenated string is a string that exactly contains all strings of any permutation of words concatenated.

  1. Input: a string s and an array words.
  2. Output: all starting indices of substrings in s that are a concatenation of each word in words exactly once.
  3. Order: the answer can be returned in any order.
public List<Integer> findSubstring(String s, String[] words)
Example 1
Input: s = "barfoothefoobarman", words = ["foo", "bar"]
Output: [0, 9]
At index 0, substring "barfoo" is "bar" + "foo". At index 9, substring "foobar" is "foo" + "bar".
Permutation example
If words = ["ab", "cd", "ef"], then "abcdef", "abefcd", "cdabef", "cdefab", "efabcd", and "efcdab" are valid concatenated strings.

Question: find every starting index in s where such a concatenated substring begins.

Correct approach: Sliding window by word length

Because all words have the same length, scan each offset modulo word length and maintain counts inside a moving window.

Show Java solution 
public List<Integer> findSubstring(String s, String[] words) {
    List<Integer> result = new ArrayList<>();
    if (s == null || words == null || words.length == 0) return result;

    int wordLen = words[0].length();
    int wordCount = words.length;
    int totalLen = wordLen * wordCount;
    if (wordLen == 0 || s.length() < totalLen) return result;

    Map<String, Integer> required = new HashMap<>();
    for (String word : words) {
        required.put(word, required.getOrDefault(word, 0) + 1);
    }

    for (int offset = 0; offset < wordLen; offset++) {
        Map<String, Integer> window = new HashMap<>();
        int left = offset;
        int matched = 0;

        for (int right = offset; right + wordLen <= s.length(); right += wordLen) {
            String word = s.substring(right, right + wordLen);
            if (!required.containsKey(word)) {
                window.clear();
                matched = 0;
                left = right + wordLen;
                continue;
            }

            window.put(word, window.getOrDefault(word, 0) + 1);
            matched++;

            while (window.get(word) > required.get(word)) {
                String leftWord = s.substring(left, left + wordLen);
                window.put(leftWord, window.get(leftWord) - 1);
                matched--;
                left += wordLen;
            }

            if (matched == wordCount) {
                result.add(left);
                String leftWord = s.substring(left, left + wordLen);
                window.put(leftWord, window.get(leftWord) - 1);
                matched--;
                left += wordLen;
            }
        }
    }

    return result;
}
concatenation: phép nối chuỗi permutation: hoán vị sliding window: cửa sổ trượt
